Each pack is a directory of plain text plus a `pack.json` naming every file
with its licence and its SHA-256. The licences differ file by file — glosses are
unencumbered, frequency ranks CC BY-SA, lemma lists ODbL — so each file carries
its own attribution header and NOTICE covers the whole. Nothing here is code.

Generated by `tools/publish/packs.ts`; do not hand-edit.
